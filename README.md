# JoJo Archive

A visual character archive inspired by **JoJo's Bizarre Adventure**, covering the main protagonists across Parts I–IX in a single themed experience.

## Overview

The project is a static front-end showcase built around large character sections, custom visual themes, responsive layouts, and part-to-part navigation.

Each section presents its character with dedicated artwork, atmosphere, abilities, timeline information, and supporting details.

## Featured Characters

- Jonathan Joestar
- Joseph Joestar
- Jotaro Kujo
- Josuke Higashikata
- Giorno Giovanna
- Jolyne Cujoh
- Johnny Joestar
- Josuke “Gappy” Higashikata
- Jodio Joestar

## Features

- Part I–IX navigation
- Character-specific visual themes
- Responsive hero layouts
- Animated decorative layers
- Character information cards
- Feature and ability sections
- Smooth in-page navigation
- Custom typography and visual effects

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive web design
